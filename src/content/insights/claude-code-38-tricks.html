#10

Im Plan Mode beginnen

WorkflowBasics

Shift+Tab wechselt in den Plan Mode. Claude darf lesen und recherchieren, aber nichts ändern. Es skizziert Schritte, stellt Rückfragen und legt den Ansatz fest, bevor Code entsteht. Passt der Plan, raus aus dem Modus und ausführen lassen.

Tipp

Nicht für alles: Wenn ihr den Diff in einem Satz beschreiben könnt (Tippfehler, Variable umbenennen), direkt machen lassen. Mit Ctrl+G öffnet ihr den Plan im Editor und könnt ihn selbst anpassen.

#38

Rechte gezielt freigeben statt alles erlauben

KonfigPro

Der Schalter --dangerously-skip-permissions macht Claude schnell, heißt aber nicht ohne Grund so. Besser: sichere Befehle ausdrücklich erlauben, zerstörerische ausdrücklich verbieten. Die Deny-Liste hat immer Vorrang. So bekommt ihr fast dasselbe Tempo ohne das Risiko.

Tipp

/permissions öffnet einen Dialog für die Regeln, /sandbox isoliert Datei- und Netzwerkzugriff. Neuere Versionen haben zusätzlich einen Auto-Modus, in dem ein Prüfmodell riskante Aktionen blockiert.

.claude/settings.json
{
  "permissions": {
    "allow": [
      "Bash(npm run test *)",
      "Bash(npm run lint)",
      "Bash(git status)",
      "Bash(git diff *)"
    ],
    "deny": [
      "Bash(rm *)",
      "Bash(git push --force *)",
      "Read(./.env)"
    ]
  }
}

    Einordnung

    Kritisch betrachtet

    • Werkzeuge ändern sich schnell

      Befehle und Features wie Agent-Teams sind teils experimentell. Was in eurer Version verfügbar ist, zeigt /help bzw. die Doku auf code.claude.com.

    • Zahlen sind Faustregeln

      „Bei 60 % compacten“, „max. 200 Zeilen CLAUDE.md“ oder „ca. 32.000 Tokens bei ultrathink“ sind Erfahrungswerte aus der Praxis, keine Spezifikation.

    • Inspiration ist nicht Kopie

      Layout-Ideen übernehmen ja, fremde Texte, Bilder und Logos nein. Urheberrecht gilt auch für KI-Nachbauten.

    • Sicherheit vor Tempo

      Ein Plugin oder Hook läuft mit euren Rechten. Nur aus vertrauenswürdigen Quellen installieren und zerstörerische Befehle auf die Deny-Liste setzen.

    • Verstehen bleibt euer Job

      Code, den ihr nicht erklären könnt, gehört nicht in die Übergabe. Lasst euch von Claude erklären, was es gebaut hat.
